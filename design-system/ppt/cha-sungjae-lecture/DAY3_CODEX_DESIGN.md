# 3주차 Codex CLI 강의 디자인

참조: `llmops-16week/week01/lecture/DESIGN_SYSTEM.md`, `PPT_PRODUCTION_GUIDELINE.md`와 해당 강의 PDF. 참조의 명암 대비·평면 그리드·코드와 설명 분할을 적용한다. 16주 과정의 일정·학교별 운영·분량 기준은 이 40시간 과정에 가져오지 않는다.

## 글자와 여백

- 1280×720 CSS px 캔버스, PowerPoint 실제 13⅓×7½ inch
- Artifact `fontSize`는 px. 실제 pt는 `px × 0.75`로 검증
- 제목 54px(40.5pt), 본문 28~30px(21~22.5pt), 표 26px(19.5pt), 코드 24px(18pt), 경로·페이지 20px(15pt)
- 일반 고딕 `AppleGothic`, 코드 `Menlo`, 제목과 본문 같은 글꼴 계열
- 좌우 64px, 상단 40px, 본문 180~620px, 하단 660px 이후 20px 크기의 페이지 정보
- 표는 3~4열, 셀의 명시적 개행과 가장 긴 내용에 맞는 가변 행 높이
- 제목은 짧은 명사형, 본문은 구체적인 입력·동작·관찰 결과
- 코드 장표는 8~12줄과 입력·관찰·변경 이유를 함께 표시

## 색상과 구성

`#050505`, `#191919`, `#FFFFFF`, `#F7F8FA`, `#667085`, `#D0D5DD`를 기본으로 사용한다. 네이비 `#0B1F3A`, 파랑 `#2563EB`는 현재 주차·변경 변수처럼 의미가 있는 경우만 사용한다. 마지막 열·항목은 같은 위계의 다른 항목과 같은 색이다.

표지, 어두운 차시 구분, 평면 비교표, 코드와 해설, 실패·수정 결과 비교, Mermaid 아키텍처, 실제 실행 화면을 교차 사용한다. 같은 구조를 세 장 연속 배치하지 않는다. 카드형 대시보드와 장식 이미지는 사용하지 않는다.

## 실습과 메시지 검증

1. 실습은 코드 입력·수정·실행·관찰·테스트 중 실제 활동을 포함한다.
2. JSON 저장은 보조 기록이다. 학습 결과는 코드의 동작과 수정 전후의 차이로 설명한다.
3. 학생에게 필요한 파일·명령·입력·실패 조건·복구 순서를 장표에 제공한다.
4. `경계`, `정상`, `외부 쓰기` 같은 단독 레이블은 구체적인 허용 조건·실패 조건·외부 서비스 변경으로 표현한다.
5. LLM 호출, Coding Agent의 도구 선택, Python Workflow, 사람의 최종 판단을 구분한다.
6. 로컬 Codex CLI는 PC에서 실행되는 클라이언트다. 모델 추론은 연결된 서비스에서 수행되며 계정 권한·이용 한도·인터넷 연결을 필요로 한다.
7. Live Codex 응답, 재생 Fixture, 설명용 예상 결과를 서로 구별한다.
8. 원본 6개 모듈과 실제 5주차 운영의 순서를 구분하고, 앞서 진행한 회의기록 실습의 활용 관계를 명시한다.
9. 5주차 15~18시 프로젝트 구간은 제작 150분과 후반 30분의 휴식·Q&A다. 의무 발표는 두지 않고 개선 전후 설명 문서나 짧은 화면 기록을 선택한다.
10. 전체 장표의 제목·설명 중복과 실제 px/pt, 개행·잘림·캡처 판독성을 검수한다.
