# Codex CLI 실행 사례와 사람 검증

2026-09-12, 로컬 `codex-cli 0.151.0`으로 실제 실행했습니다. 기본 선택 모델은 `gpt-5.6-sol`, sandbox는 `read-only`였습니다. 기존 CLI 인증을 사용했으며 계정 사용량이 적용됩니다. 무료·무제한 이용을 보장하지 않습니다.

## 요청 범위

- 읽기: `review_policy.md`, `fixtures/checkout.py`, `fixtures/checkout_checks.py` 세 파일.
- 요청: 초과 쿠폰과 잘못된 입력의 사용자 영향, 재현 입력, 최소 수정, 기존 테스트 이름.
- 금지: 파일 수정, 상위 폴더 읽기, Git 작업, 원격 게시, 테스트 실행.
- 출력: Markdown 리뷰 2건 이내.

## 확인된 결과

| 항목 | 실제 응답 | 사람 검증 |
|---|---|---|
| 초과 쿠폰 | 1,000원−5,000원 = −4,000원 | 코드 계산식과 일치 |
| 잘못된 입력 | 음수 가격·쿠폰, 수량 0 거절 필요 | 제공 제품 규칙·테스트와 일치 |
| 파일 줄 | `fixtures/checkout.py:5` | **오류: 계산식은 6행**, 5행은 docstring |
| 테스트 | 미실행이라고 명시 | 실제 CLI는 파일 읽기만 수행 |

의미 있는 결함을 찾았더라도 위치 정보까지 정확하다는 보장은 없습니다. 원문을 사람이 고친 뒤 모델 원문인 것처럼 보여 주지 않습니다. 제공 PR 리뷰 생성기는 변경 줄 검사도 하므로 이 틀린 줄 번호를 그대로 사용하면 수정이 필요합니다.

## 학생에게 보여줄 순서

1. 아래 실제 응답을 먼저 읽습니다.
2. `fixtures/checkout.py`에서 줄 번호를 확인합니다.
3. 응답의 5행과 실제 계산식의 6행 차이를 찾습니다.
4. 재현 입력은 별도 로컬 pytest로 확인합니다.
5. 중요도·사용자 영향도 사람의 제품 판단으로 최종 결정합니다.
