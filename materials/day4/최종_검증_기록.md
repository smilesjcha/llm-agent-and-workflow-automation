## 문서·화면 검사

- Excel: 14개 업무, 28명·40문항 합성 답안. LibreOffice에서 실제 재계산한 값과 별도 Python 기준 계산을 비교했습니다. 수식 오류 0개이며 입력 변경 후 지연 업무 수·채점 대상 인원 변화를 확인했습니다.
- Word: 개선 전·후 각 1페이지. DOCX를 PDF와 이미지로 렌더해 페이지 구성과 한국어 표시를 확인했습니다. 숫자 검사는 의미 전체를 보증하지 않으므로 사실 확인은 사람이 완료합니다.
- 보고서 PPT: 제작 예제와 학생 공개 라이브러리 예제 모두 7장. 강의용 145장 PPT와 다른 결과물입니다.
- 강의 PPT: 패키지 무결성, 전체 56개 native table, 글꼴 정책, 제목·bullet 배치 검사 통과. PDF 전환 후 145페이지를 전부 이미지로 렌더했습니다.
- 시각 검수: 1–145페이지를 각각 확인했습니다. 작은 캡처, 시간표 개행, 하단 설명의 간격을 수정했습니다. 최종 수정본은 이전 검수본과 PNG 해시를 비교해 변경 없는 페이지를 확인하고, 변경된 페이지를 다시 개별 검수했습니다.
- 한국어 PDF: 나눔고딕을 포함한 폰트 설정으로 변환했습니다. LibreOffice PDF 결과를 확인했으며, 모든 OS의 PowerPoint·프린터 조합을 검증한 것은 아닙니다.

## 확인 범위와 제한

| 구분 | 확인한 것 | 확인하지 않은 것 |
|---|---|---|
| 실제 Codex | 로컬 CLI 리뷰 1회, 원문·줄 번호 비교 | 모든 계정·모델에서의 동일 응답 |
| 선택 CLI adapter | 성공·실패·timeout·권한·출력 경계의 mock 검사 | 이 adapter 경유 추가 유료/실시간 실행 |
| GitHub 실습 | 공개 PR 읽기 코드, 로컬 승인·게시 미리보기, CI 양식 | 실습 예제를 실제 PR에 자동 게시 |
| 원본 성적표 | 파일 형식 메타데이터와 사용자 제공 이미지 | 원본 학생 셀·수식 읽기, 원본 수정 |
| Google Sheets | 합성 시트 생성 코드, 수식·CF의 로컬 검사 | 계정에서 Apps Script 설치·실행 |
| Claude | 공식 기능 자료와 대화 요청 예시 | Claude Desktop 실제 실행·화면 캡처 |

실제 Codex의 잘못된 줄 번호는 원문을 보존하고 [별도 검증 기록](Codex_실행사례_및_검증.md)에 표시했습니다. 원격 게시와 원본 덮어쓰기는 기본 실습에서 수행하지 않습니다. 테스트 통과가 자동 병합 승인을 뜻하지 않습니다.

`git diff --check`의 예외는 저장한 Codex 원문과 그 HTML 안의 Markdown 줄바꿈용 끝 공백 네 곳입니다. 모델 원문 보존을 위해 수정하지 않았으며, 두 증거 파일을 제외한 변경 파일의 공백 검사는 통과했습니다.
