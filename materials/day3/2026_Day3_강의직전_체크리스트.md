## 30분 전

배포 경로는 `codex/day3-review-intelligence` branch 또는 학생용 ZIP이다. 학생이 기본 main을 clone해 이전 자료를 받지 않았는지 확인한다.

코드 ZIP에서는 `python scripts/run_day3_preflight.py --code-only`를 사용한다. PPT·PDF·실행 결과 Notebook은 별도 배포다. ZIP의 코드 검사 PASS와 별개로 2차시 Git 실행을 위해 `git --version`을 확인한다.

```bash
python -m pip install -r requirements-day3.txt
codex --version
codex login status
python scripts/run_day3_preflight.py
python -m pytest -q tests/test_day3_review_copilot.py tests/test_day3_notebook.py
```

| 확인 | 통과 기준 |
|---|---|
| Kernel | 수업용 Python·필수 library import 가능 |
| CLI | 설치·로그인·계정 사용 가능 상태 각각 확인 |
| 화면 가독성 | PPT·PDF의 코드·표·캡처 글씨가 확대 없이 읽힘 |
| 음수 결제 시연 | 초안 -2,000원·수정 후3,000원 |
| 배송비 시연 | 초안40,000원·수정 후43,000원 |
| 실제 Test | 초안9개 중7개 실패·수정 후9개 통과 |
| 실제 AI 리뷰 | `RUN_CODEX_LIVE=True` 실행·Provider codex_cli |
| 예제 경로 | False 선택 시 제공된 예제 리뷰라고 표시 |
| Notebook 출력 | `output/course-labs/day3-v2/student-run/` |
| 학생 작업 보존 | 매 실행 고유 폴더 생성·원본 fixture 변경 없음 |

1. 오프닝에 쓸 초안·수정 버전 화면 준비

6. 11:30~13:00, 14:40~15:00, 17:30~18:00 휴식·Q&A 안내 확인

## 마감 확인

각 차시 50분, 중간 별도 휴식 없음, 연강 끝 휴식 배치. GitHub Draft PR·댓글 자동화의 상세 실습은 4주차로 연결한다. `@codex review`는 GitHub 연동이 준비된 저장소에서 선택적으로 다루며 오늘 Local Codex CLI 사용과 구분한다. Notebook은 `external_write=false`, 자동 Merge 비활성이다.

5주차 미니 프로젝트 3시간은 제작·검증·정리150분+휴식·Q&A30분이다. 온라인 개인 실습이며 학생 발표 의무는 없다. 희망자는 개선 전후1page 또는 짧은 데모를 공유한다.
