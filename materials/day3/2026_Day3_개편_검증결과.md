## 실제 실행과 수업용 재현의 구분

- **실제 모델 리뷰:** `output/day3-redesign/live-evidence/review.md`. Codex CLI 호출 성공, 지적 4건, `provider_used=codex_cli`, `fallback_reason=null`. 특정 모델 이름을 추정하지 않고 CLI 기본 선택으로 기록했다.
- **실제 코드 수정:** `output/day3-redesign/codex-authoring-demo/`. 요청문, Codex 응답, 수정 Diff, 테스트 전후 기록을 제공한다. 테스트는 그대로 유지하고 `checkout.py`만 변경했다. 7개 실패 → 9개 전체 통과, 음수 결제 -2,000원 → 3,000원.
- **실제 Notebook 연동:** 별도 Live 전체 실행에서 리뷰 후보 4건과 Human Review 수정·재개, 테스트 통과, 같은 파일의 HTTP 결과를 확인했다. 수강생 정본의 기본값은 비용·계정 없이 실행 가능한 Fixture다.
- **실제 화면:** `assets/screenshots/day3-codex-cli-*.png`는 이 저장소의 Localhost 서비스를 직접 실행해 캡처한 화면이다. 서비스 전체·계산·테스트·Codex 리뷰를 포함하며 목업이 아니다. PPT에는 해당 영역을 확대해 사용한다.

## 검증 범위와 남은 사용자 확인

1. 실제 Codex 실행은 이 Mac의 로그인 계정에서 검증했다. 학생별 계정·사용 한도·학교 네트워크는 개별 확인이 필요하다. 로컬 CLI가 로컬 모델이라는 뜻은 아니다.
2. Windows 전용 설치 실행·Windows PowerPoint의 글꼴 대체는 이 환경에서 직접 검증하지 않았다. PDF를 함께 배포하며 Windows 설치/실행 명령은 가이드에 별도 표기했다.
3. PR 게시·댓글·merge 같은 외부 서비스 변경은 자동 실행하지 않는다. 4주차는 본인 저장소·대상 Diff·사람 확인 뒤 단계적으로 진행한다. 현재 3주차 변경은 Draft PR에서 검토한다.
4. `llmops-16week`의 명암 대비·그리드·코드 설명 분할을 디자인에 반영했다. 해당 과정의 내용이나 시간표를 가져오지는 않았다.
5. 4·5주차의 최신 시간별 운영 계획은 `4·5주차_운영안_및_미니프로젝트.md`와 3주차 후반 장표에 있다. 기존 4·5주차 240장 PPT는 이전 초안이며 이번 변경의 최종 PPT 대상은 3주차다.
