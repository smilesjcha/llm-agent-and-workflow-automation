# 공개 한국어 회의 음성 가이드

## 수업 자산

| 구분 | 경로 | 용도 |
|---|---|---|
| 공개 원본 목록 | `data/day2_public_audio/sources.json` | 출처·저작자·라이선스·원본 fingerprint |
| 실제 회의 발췌 | `data/day2_public_audio/meeting_ko_ccby_excerpt_10m.mp3` | build 성공 후 STT 기본 입력 |
| 비식별 fallback | `data/meeting_sample_ko_12min.wav` | 오프라인·네트워크 실패 시 입력 |
| SHA-256 명세 | `data/day2_public_audio/SHA256SUMS` | 수업 전 파일 무결성 확인 |

Notebook과 강의 코드는 특정 파일이 반드시 존재한다고 가정하지 않는다. 아래 명령의 `path`를 STT 입력으로 사용한다.

```bash
python3 scripts/day2_public_audio.py resolve
# 경로만 필요할 때
python3 scripts/day2_public_audio.py resolve --path-only
```

공개 excerpt가 있으면 CC BY 4.0 자료를, 아직 만들지 않았거나 외부 연결이 막히면 기존 합성 회의 음성을 선택한다. fixture fallback은 실패를 성공으로 숨기는 장치가 아니라, 외부 네트워크 문제와 STT 기능 문제를 분리하기 위한 수업 안전장치다.

이 자료의 선택 이유는 공개 라이선스, 한국어 발화, 복수 화자, 고유명사, 현장 음향이 함께 존재하기 때문이다. 정치적 주장이나 정당을 평가하는 자료가 아니며, 강의 또는 강사가 저작자·출연자·정당의 지지나 보증을 받았다는 의미도 아니다. 요약 결과 역시 정치적 평가가 아니라 STT 품질, 근거 연결, Action Item 생성 가능성만 검증한다.

## 생성 절차

### 1. 준비

macOS:

```bash
brew install ffmpeg
```

Windows PowerShell에서 winget을 사용할 수 있는 경우:

```powershell
winget install --id Gyan.FFmpeg -e
```

설치 확인:

```bash
ffmpeg -version
ffprobe -version
```

### 2. 정책과 명령 사전 확인

```bash
python3 scripts/day2_public_audio.py catalog
python3 scripts/day2_public_audio.py dry-run
```

`dry-run`은 네트워크를 호출하거나 파일을 쓰지 않는다. 시작 시각, 길이, codec, sample rate, 출력 경로가 맞는지 먼저 확인한다.

### 3. 라이선스·원본 검증

```bash
python3 scripts/day2_public_audio.py verify-source
```

Wikimedia Commons API에서 다음 항목을 다시 확인한다.

- MIME type: `video/webm`
- 원본 byte size
- 원본 SHA-1 fingerprint
- 라이선스: `CC BY 4.0`
- 저작자 attribution
- Wikimedia upload HTTPS URL

하나라도 카탈로그와 다르면 `SOURCE_METADATA_MISMATCH`로 종료한다. 라이선스가 바뀌었는데 과거 정보를 믿고 계속 내려받지 않는다.

### 4. 10분 excerpt 생성

```bash
python3 scripts/day2_public_audio.py build
```

스크립트는 398 MB 원본 WebM을 저장소에 저장하지 않는다. Commons가 제공하는 저대역폭 `240p.vp9.webm` derivative를 ffmpeg으로 순차 처리해 05:00~15:00만 남긴다. 성공 시 다음 작업을 원자적으로 완료한다.

1. `.part` 임시 파일 생성
2. 16 kHz mono MP3 변환
3. ffprobe로 `600±2초` 확인
4. 목표 파일로 교체
5. `SHA256SUMS` 갱신

정상 결과 예시:

```json
{
  "status": "BUILT",
  "path": "data/day2_public_audio/meeting_ko_ccby_excerpt_10m.mp3",
  "duration_seconds": 600.0,
  "sha256": "..."
}
```

### 5. 수업 전 검증

오프라인 검증:

```bash
python3 scripts/day2_public_audio_verify.py
```

원본 라이선스까지 다시 확인하는 온라인 검증:

```bash
python3 scripts/day2_public_audio_verify.py --live
```

## 예상된 실패와 복구

| 코드 | 의미 | 수업 복구 |
|---|---|---|
| `FFMPEG_NOT_FOUND` | ffmpeg 또는 ffprobe 미설치 | 설치 후 재실행하거나 `resolve` fallback 사용 |
| `SOURCE_METADATA_UNAVAILABLE` | 네트워크·Commons API 문제 | 합성 fixture로 수업 지속 |
| `SOURCE_METADATA_MISMATCH` | 원본·라이선스·저작자 정보 변화 | 다운로드 중단, 강사가 출처 재검토 |
| `EXCERPT_DURATION_MISMATCH` | 발췌 결과 길이 오류 | `.part` 제거 후 다시 build |
| `CHECKSUM_MISMATCH` | 수업 파일 변조·불완전 복사 | 원본 삭제 후 build 재실행 |
| `FALLBACK_AUDIO_NOT_FOUND` | 배포 bundle 누락 | 강사용 bundle 다시 복사 |

## 저장소에 포함하지 않는 서울시의회 영상

[서울특별시의회 영상회의록](https://ibs.smc.seoul.kr/kr/cast/vod.do)은 실제 한국어 회의와 공식 회의록을 함께 볼 수 있어 자료 탐색 링크로는 유용하다. 하지만 해당 페이지는 서울특별시의회 회의규칙 제49조의3에 따라 회의 동영상을 상업적 목적으로 사용할 수 없다고 명시한다.

따라서 이 과정에서는 다음을 금지한다.

- 영상 자동 다운로드
- 음성 발췌 파일 저장소 포함
- 유료 교육 bundle 재배포
- 라이선스가 명확하지 않은 구간을 공개 Demo에 사용

수강생이 원문 페이지를 선택적으로 확인하는 링크로만 제공한다. 상업 이용 가능 여부가 불분명한 자료를 “공개되어 있다”는 이유만으로 실습 파일에 포함하지 않는다.

## 강의 진행 권장안

| 시점 | 강사 화면 | 수강생 실행 | 확인 증거 |
|---|---|---|---|
| 수업 전 | `--live` 검증과 build | 없음 | 라이선스·SHA-256 `VERIFIED` |
| 1차시 | 원본·excerpt·fallback 차이 | `resolve` | 실제 선택된 입력 경로 |
| 2차시 | 같은 adapter에 실제·fixture 입력 | STT 실행 | timestamp segment JSON |
| 3차시 | 잡음·고유명사·화자 전환 오류 | 품질 Gate 실행 | `READY/HOLD`와 이유 |
| 5차시 | segment ID를 유지한 chunk | chunk 코드 수정 | evidence ID 보존 |
| 7차시 | 근거 없는 Action Item 주입 | validator 실행 | unknown evidence 차단 |
| 8차시 | 실제 파일과 fixture 결과 비교 | scorecard 생성 | 오류 유형과 개선안 |

실제 회의는 “더 좋은 결과가 나오는 정답 파일”이 아니다. fixture는 기능 회귀를 재현하고, 실제 파일은 음향·발화·고유명사 때문에 발생하는 현실적 실패를 드러내는 입력이다. 두 결과를 함께 비교해야 STT Demo가 운영 가능한 품질 Gate로 발전한다.
