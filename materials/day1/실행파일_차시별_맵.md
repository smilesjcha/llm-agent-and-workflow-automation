# 1일차 실행 파일·활동 분류 맵

## 한 번에 전체 검증

```bash
source .venv/bin/activate
python scripts/run_day1_preflight.py
```

수강생에게 GitHub 없이 별도 파일로 제공할 때는 아래 ZIP을 만든다.

| 5차시 | `ollama_tool_agent`·`SafeToolExecutor` | 실제/fixture planner→validator→executor | workspace 이탈·모델 연결 실패 정규화 | 모델 제안과 코드 권한 분리 확인 | 준비 |

판정 기준은 “설명 자료가 있는가”가 아니라 다음 네 항목이 모두 있는가이다.

1. 수강생이 직접 여는 코드 또는 notebook
2. 복사해 실행할 명령
3. 정상과 실패를 확인하는 자동 test 또는 구조화 결과
4. 사람이 최종 판단하는 승인·리뷰·READY/HOLD 지점

강사와 수강생 모두 실행 실패 시 raw traceback 전체를 따라가지 않고 첫 오류·현재 Python 경로·작업 폴더를 먼저 확인한다.
