# 1일차 강사 회의음성 라이브 Demo 런북

## 결론

구두 설명만으로 끝내지 않는다. 30~60초짜리 한국어 회의 음성을 한 번 실제로 넣어 전사 → 회의 결과 JSON → 휴먼 승인 필요 → 자동 메일 발송 차단을 보여준다.

다만 수업 성공을 실시간 모델 다운로드나 네트워크에 맡기지 않는다. 라이브 경로, 사전 실행 결과, 텍스트 fixture의 세 경로를 동시에 준비한다.

## 수업 전 15분 점검

1. 본인이 직접 녹음한 30~60초 WAV 파일을 data/demo_meeting.wav로 둔다.
2. 개인정보·회사명·실제 고객 정보가 없는지 다시 듣는다.
3. 선택 사항인 로컬 STT를 설치한다.

~~~bash
python3 -m pip install -r requirements-stt-optional.txt
~~~

4. 아래 명령을 한 번 실행한다.

~~~bash
python3 -m src.meeting_demo \
  --audio data/demo_meeting.wav \
  --transcript data/demo_meeting_transcript.txt \
  --out output/day1-demo
~~~

5. 다음 두 파일을 VS Code에 미리 열어둔다.

~~~text
output/day1-demo/transcript.json
output/day1-demo/meeting_result.json
~~~

6. 터미널 글자 크기를 키우고 API key·사용자 경로·알림을 화면에서 치운다.

## 강의 중 4분 Demo

1. WAV 파일 길이와 비식별 여부를 10초 안에 설명한다.
2. 한 줄 명령을 실행한다.
3. mode=local_stt인지 확인한다.
4. transcript.json에서 원문 segment와 시각을 보여준다.
5. meeting_result.json에서 요약·결정·담당자·기한·evidence ID를 보여준다.
6. automatic_email=false, requires_human_approval=true를 마지막에 보여준다.

핵심 메시지는 “요약이 예쁜가”가 아니라 “근거와 금지 행동이 결과에 남았는가”이다.

## 실패했을 때 20초 복구

- 오디오·모델·패키지 오류가 발생해도 같은 명령이 자동으로 transcript fixture를 사용한다.
- 터미널의 mode=fixture와 fallback_reason을 보여주고, 이것도 설계된 예외 처리라고 설명한다.
- 이미 생성한 output/day1-demo/meeting_result.json을 열어 수업을 계속한다.

## 수강생 실습 범위

첫 시간에는 수강생 모두에게 STT 설치를 요구하지 않는다. 강사 Demo를 본 뒤 수강생은 입력·원하는 결과·금지 행동을 한 문장으로 작성한다. 로컬 STT 설치와 직접 음성 실행은 1일차 8차시에서 선택 실습으로 다룬다.
