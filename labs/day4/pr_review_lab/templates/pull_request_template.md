## 변경 목적

쿠폰 사용 후 결제액이 음수가 되는 문제 및 잘못된 주문 입력 처리.

## 변경 파일

- `exercise/checkout.py`: 입력 검사와 최소 결제액 처리
- `exercise/test_checkout.py`: 정상·초과 쿠폰·잘못된 입력 검증

## 테스트

- [ ] 수정 전 실패 재현
- [ ] 수정 후 `python -m pytest -q test_checkout.py` 통과
- [ ] 기존 정상 쿠폰 계산 유지

## 사람 확인

- [ ] 리뷰 의견이 실제 변경 줄과 연결됨
- [ ] 가격·수량·쿠폰 정책이 제품 요구와 일치함
- [ ] 비밀키·개인정보·실제 고객 데이터 없음
- [ ] AI 리뷰와 CI 결과를 확인하고 사람이 merge 여부 판단
